# ЗЗ — запросы и заявки

Пример: [задача 410712](https://resultforyou.ru/workgroups/group/437/tasks/task/view/410712/) (удалить запросы + проверить заявку + отчество — смешанный с ТЧ).  
ССП: [задача 403256](https://resultforyou.ru/workgroups/group/437/tasks/task/view/403256/).

## Правила

- **Запросы удаляем всегда** (если письмо просит удалить запросы).
- **Заявку удаляем**, если есть отказ **по мошенничеству** или **нет подписанной анкеты**.
- Любой отказ (автоотказ, «отказался», «отказано клиенту») → всё равно проверить мошенничество **и** анкету.
- Запросы в рамках этого сценария инструкции **удаляются в НБКИ**; в ОКБ и Экви — отдельным файлом-просьбой, см. ниже.

## Заявка: найти и проверить

1. Если в Исх «к Вам относятся заявки» — УИД/дата во **втором файле (Вх)** или ниже по тексту.
2. ПО: клиент → История → заявка/договор на указанную дату.
3. Отказ по мошенничеству? Если да — исключение заявки (ниже).
4. Файлы: объект = эта заявка, папка слева от строки → ищем **электронную подпись** анкеты.
5. Подпись есть → смотрим, как заявка отображается в бюро (не удаляем из-за «просто отказ»).

Проверка заявки в бюро:

- **ОКБ** — по паспорту, вкладка «Обращения», колонка «Код причины отказа» (таблица кодов — скрин Word).
  - заявка отклонена / клиент отказался → код **1**;
  - ещё не отклонена или уже выдана в договор → **NULL**.
- **НБКИ** — поле «УИД заявки».
- **Экви** — удобнее по УИД; «код стадии» / «отказано источником» = 1.

## Удаление запросов по бюро

### НБКИ

Эти запросы удаляются **только в НБКИ** файлом.

1. Заполнить excel по образцу в Word.
2. Имя файла скриптом (`@keyOH`: 1 — МФК, 4 — ЦВ, 5 — ПКО, 6 — МКК):

```sql
DECLARE @Date AS NVARCHAR(8),
        @Time AS NVARCHAR(6),
        @keyOH AS INT = 1  -- 1 МФК, 4 ЦВ, 5 ПКО, 6 МКК
SET @Date = FORMAT(GETDATE(), 'yyyyMMdd')
SET @Time = FORMAT(GETDATE(), 'HHmmss')
SELECT FORMATMESSAGE('%s_%s_%s', S.NBKI_Memb_KI, @Date, @Time)
FROM Sett AS S (NOLOCK)
WHERE S.keySett = @keyOH
```

Пример имени: `WD01BB000002_20240620_131602`.

3. Подписать и зашифровать актуальными сертификатами.
4. Итог: `{имя}.xlsx.zip.enc` (расширение `.sig` стереть вручную).
5. Письмо на **CancelCreditHistory@nbki.ru**: просьба удалить запрос в рамках оспаривания и дать обратную связь.
6. **Финальный ответ на оспаривание — только после ответа НБКИ**, что запросы удалены.

### ОКБ

1. Скрипт ответов ([07-otvet-i-zakrytie.md](07-otvet-i-zakrytie.md)), в `@answer` текст-просьба удалить запрос (подставить свои ФИО, паспорт, дату запроса, номер входа). Шаблон — в Word, блок про Жаркун.
2. Имя PDF: `DIV_{код}_{ГГГГММДД}_{фамилия}.pdf`  
   Коды: Саммит **01465**, ПКО Доброзайм **02680**, МКК ДЗБР **02650**.  
   Пример: `DIV_01465_20231221_Zharkun.pdf`.
3. Отправка:
   - сервис загрузки (если есть доступ);
   - иначе: zip → подпись → шифр → `{имя}.zip.pem.pem` → s-tp2 → Weblink `https://weblink.bki-okb.com/cfb/ui/login` (учётки в Passwork: ТП ПО → Внешние сервисы → БКИ → ОКБ → YVSobko / PPAnosova / VABurova);
   - либо загрузка из ЛК ОКБ (скрины Word).
4. Письмо на **sd@bki-okb.ru**: файл загружен на Weblink, имя файла.
5. Если **больше ничего не требовали** — это и есть ответ на оспаривание, задачу **можно закрыть сразу**.

### Эквифакс (Скоринг Бюро)

1. Тот же скрипт ответов, в `@answer` просьба удалить запрос (организация в тексте — АО «БКИ «Скоринг Бюро»»).
2. Имя: `0OA_del_zapros_{фамилия}_{ДДММГГГГ}.pdf`.
3. Сервис **или** zip+подпись+шифр → S-tp2, папка **correction/inbox**.
4. Письмо на **bki_exchange@scoring.ru**: выложили файл, имя, просим ОС.
5. Когда Экви подтвердит удаление — **второй** файл-ответ: `0OA_otvet_na_zapros_{фамилия}_{ДДММГГГГ}`, в тексте «запрос от … удалён в файле …».
6. Финал не раньше подтверждения Экви.

## Удаление самой заявки

Тип выгрузки **исключение договора/заявки** (3.3/3.4).

Старый формат НБКИ иногда не удаляет заявку обычным исключением: в событие **3.4** в XML вручную добавить поле `<num>` с `keyDZ` заявки.

После формирования в ПО:

1. Сохранить файл с именем как у выгрузки в ПО.
2. **Отменить** выгрузку в ПО, чтобы не было двух файлов.
3. Подписать ЭП организации, зашифровать шифром НБКИ.
4. Отправить: `https://icrs.nbki.ru/inout/uploadGUTDF.html`.
5. ЛК НБКИ → «Результаты обработки GUTDF-файлов» → скачать квитанцию → расшифровать (организацию не выбирать) → `eventsAccepted`.
6. Поиск заявки по ПДн, затем по УИД заявки. Не находится → удалена.

## Запросы ССП

Часто во вложении файл **другого** бюро (оспаривание от НБКИ, а удалить надо запросы ОКБ/Экви).

В `@answer` скрипта:

- ОКБ: `просим удалить запрос от ДД.ММ.ГГГГ (ССП) в АО «ОКБ»`
- Экви: `просим удалить запрос от ДД.ММ.ГГГГ (ССП) в АО «БКИ «Скоринг Бюро»`

Файл назвать «Ответ на оспаривание [Фамилия]», подписать, зашифровать, отправить в бюро, **от которого пришло само оспаривание**. Задачу можно закрыть сразу.

## Смешанный ЗЗ + ТЧ + ОЧ

Как в примере 410712: удалили запросы, заявку проверили, отчество правили по контуру ТЧ. Финальный ответ — **после** подтверждения НБКИ по запросам **и** после приёма титульной корректировки, одним письмом по всем пунктам.
