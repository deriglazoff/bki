## Статусы выгрузки (`KI_UnloadList.Status`)

Значения из инструкции (полный справочник — `KI_UploadStatus_Config`):

| Код | Смысл в процессе 3.1 / ОЧ |
|-----|---------------------------|
| 13 | Готово к выгрузке (после смены даты события и пересборки XML) |
| 21 | Отправлено (грязная выгрузка с неверным титулом) |
| 23 | Отмена (корректировочная, пока собираем 3.1; для ДЗБР — уже первая) |
| зелёный «Отправлено» на форме | ОЧ: ждать и смотреть квитанцию |
| жёлтый | Ошибки валидации |

Квитанция: `records_incorrect = 0`.

## События

| Код в деталях | Смысл |
|---------------|--------|
| 28 в `KI_CreditHistoryList_Detail` | Собралось событие **3.1** |
| 3.1 | Корректировка титула |
| 3.2 | Корректировка договора |
| 3.3 / 3.4 | Исключение договора / заявки |
| 3.5 | Исключение клиента целиком |
| 4.2 / 4.3 / 4.4 | Аннулирование одной записи / всех договоров / всех обращений |

Код изменения КИ в 3.2: **1** наша ошибка, **2** клиент, **3** мошенничество.

Банкротство в блоке 38: основание **16**. Признак учёта в блоке 54 с нашей стороны: **1**.
