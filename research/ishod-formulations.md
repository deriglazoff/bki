# Формулировки исходящих писем бюро (Исх)

Это **письма бюро источнику**, не ответы организации и не заявления субъекта (Вх / `claim`).

| Корпус | Что снято | n |
|--------|-----------|---|
| [`task-pdfs/`](../task-pdfs/) (янв–сен 2026) | все txt с именем `ИСХ…` / `Исх…` / `ishod.txt` | **678** (не 1000: столько писем ИСХ в папке) |
| [`run/`](../run/) (100 папок, дек 2025 – янв 2026) | ОКБ `Запрос_…` и Скоринг Бюро `correction_file` | 50 + 23 |

Из 678: НБКИ `ИСХ///{N}` ≈ 664; задвоение СКИ 12; БКИ КредитИнфо `Исх.ЮЛ-…` 2.

Плейсхолдеры: `{FIO}`, `{UID}`, `{DATE}`, `{N}`, `{ORG}`, `{PASSPORT}`, `{FILE}`.  
Канцелярию **не** читать как предмет — [classification.md](../classification.md) слой A.

---

## 1. НБКИ — `№ ИСХ///{N} от {DATE} г.`

Оболочка стабильная. Меняются адресат, ФИО, срок, блок предмета и (с июля 2026) абзац GUTDF / сноска про удаление запросов.

### 1.1. Канцелярия (не предмет)

**Открытие** (n≈640). Инварианты: обращение в НБКИ + заявление на оспаривание + ч. 3–5 ст. 8 218-ФЗ + проверить сведения. Варианты:

| n | Отличие |
|---|---------|
| ~390 | «от {FIO}» |
| ~250 | «{FIO}» без «от» |
| 100 | плюс **часть 12 статьи 6** |
| ~223 | «№ 218-ФЗ» вместо «№ 218» |
| ~500 | срок: «установленный законом срок* – 10 рабочих дней» |
| ~125 | срок: «не позднее {DATE} г.» (часто вместе с «выполнил запрос») |
| 6 | две фразы: «просим провести проверку… Просим предоставить ответ…» |

**GUTDF — канал email** (440; дата в тексте `С 01.10.2024`):

> С 01.10.2024 для удаления/корректировки данных переданных в базу НБКИ в форматах TUTDF/GUTDF, необходимо отправлять файл формата GUTDF на адрес электронной почты gutdf@nbki.ru. Сообщения о необходимости корректировки кредитной истории (включая информацию из титульной части), направленные в ответ на настоящий Запрос в виде официального письма обрабатываться не будут (корректировка кредитной истории не будет произведена). Удаление информации о запросах производится в порядке, предусмотренном ранее.

**GUTDF — стандартный канал** (221; дата `С 01.07.2026`):

> С 01.07.2026 для удаления/корректировки данных, переданных в базу НБКИ в форматах TUTDF/GUTDF, необходимо направлять сведения по стандартному каналу, описанному в Инструкции для начала передачи данных (раздел "Инструкция по передаче файлов с данными о кредитных историях в НБКИ в формате GUTDF"). Сообщения о необходимости корректировки кредитной истории (включая информацию из титульной части), направленные в ответ на настоящий Запрос в виде официального письма, обрабатываться не будут (корректировка кредитной истории не будет произведена). Удаление информации о запросах производится в порядке, предусмотренном ранее.

«включая информацию из титульной части» — штамп, **не** контур ТЧ.

**Штраф 15.26.3** — почти все письма (формулировка штрафа 2000–5000 / 30000–50000).

**Приложение:** копия заявления субъекта о внесении изменений и/или дополнений в КИ.

**Сноска `*` ч. 4.1 ст. 8** — подтвердить достоверность / правомерность запроса либо исправить КИ.

Новый хвост сноски (118 писем, вместе с GUTDF-2026):

> Неправомерный запрос пользователя кредитной истории из дополнительной (закрытой) части кредитной истории может быть удален только по заявлению об оспаривании неправомерного запроса субъекта кредитной истории, представленного в бюро кредитных историй.

Редко (по 1): запрос уже удаляли в НБКИ, но он «также содержится в Скоринг Бюро» / «также содержится в ОКБ».

Слоты комбинируются (заявки + кредит + запросы + титул).

Подтип ОЧ из голого слота «Кредит {UID}» **не** ставить. Исключение — фраза «относительно факта наличия просроченных платежей».

### 1.3. Задвоение СКИ (12 писем)

Два оформления.

**A. Имя файла** `Исх. письмо в {орг} №ИСХ___… Запрос в Банк по задвоению…` — отдельный бланк:

> СКИ! {ФАМИЛИЯ1} ( {ФАМИЛИЯ2} ) {ИМЯ} {ОТЧЕСТВО} {YYYYMMDD} {МЕСТО} ( ДУЛ {PASSPORT} / … ), сообщаю следующее.  
> В Базе данных АО «НБКИ» произошло задвоение двух субъектов кредитных историй. … от {ORG} в файле содержались данные о паспортах принадлежащим разным субъектам. … `{FILE}` Заявка `{UID}` {ORG} передает предположительно чужой паспорт — СКИ2 {FIO} … Бюро просит Вас провести проверку…  
> Запросы на … разделение СКИ … demerge@nbki.ru  
> Имя файла: `ИмяПользователя_Дата_ФАМИЛИЯ_ИМЯ_ОТЧЕСТВО`  
> Тема: `Разделение СКИ Иванов И.И.`

**B. Обычный бланк `ИСХ///{N}`** (без «К Вам относится»):

> По данным АО «НБКИ» задвоение двух кредитных историй субъектов происходит из-за некорректной передачи паспортных данных {ORG}.  
> Оспариваемый паспорт передан (WD01BB) в файлах: `{FILE}` Заявка `{UID}`  
> СКИ1 {FIO} {YYYYMMDD} {МЕСТО} ( ДУЛ … )  
> СКИ2 {FIO} …  
> В данных файлах содержаться минимум два паспорта, один из которых не принадлежит субъекту {FIO}

Контур: **ЗС**.

## 2. БКИ КредитИнфо — `Исх.ЮЛ-{N}-{YEAR}` (2 письма в task-pdfs)

Не НБКИ. Заголовок: «Запрос о предоставлении информации». Предмет в Исх **не назван** — только ФИО и дата рождения субъекта; детали во Вх.

> ООО «БКИ КредитИнфо» (далее - Бюро) сообщает, что в соответствии с частью 3 статьи 8 Федерального закона от 30.12.2004 № 218-ФЗ «О кредитных историях» в Бюро обратился субъект кредитной истории {FIO} ( {DATE} г.р.) с заявлением о внесении изменений и (или) дополнений в кредитную историю.  
> На основании части 4.1 статьи 8 … Бюро просит принять к рассмотрению заявление … и в течение 10 рабочих дней … подтверждение достоверности ранее переданных сведений … либо исправить … или просьбу об удалении неправомерного запроса из дополнительной (закрытой) части кредитной истории.

Далее ст. 15.26.3. Приложение: «Обращение от субъекта КИ {FIO}». Подпись: генеральный директор.

## 3. ОКБ — `Исх. №{N}/НДО` (корпус `run/`, 50 писем)

Имя файла: `Запрос_…`. Заголовок: `Запрос` + `{ORG}`.

### 3.1. Канцелярия

> В АО «ОКБ» поступило заявление от субъекта кредитной истории от {DATE} (вход. № {N}/НДО) о внесении изменений и/или дополнений в его кредитную историю.

ФИО / дата рождения / паспорт — идентификация, не спор.

> …просим Вас представить в письменной форме в Бюро информацию, подтверждающую достоверность ранее переданных сведений … либо исправить его/ее кредитную историю в оспариваемой части…

> Ответ … не позднее 10 рабочих дней … Отказ … просим мотивировать.

Хвост (типовой пакет заявок):

> В случае необходимости удаления из кредитной истории оспариваемой субъектом информации о решении, просим удалить решение или предоставить мотивированный отказ.

### 3.2. Слоты объектов

| Заголовок | Строка |
|-----------|--------|
| Оспариваемые заявки | `- Дата заявки: {DATE}, Идентификатор обращения: {UID}` |
| Оспариваемые договоры | `- УИД: {UID}, сумма обязательства: {SUM}RUB, дата совершения сделки: {DATE}` |
| Оспариваемые запросы | `- Дата запроса: {DATE}, идентификатор ответа: {ID}` |

### 3.3. «Сведения об информации…»

| n | Формула | Контур |
|---|---------|--------|
| 39 | Заявку на кредит не оформлял | ЗЗ / Заявка |
| 2 | Кредит должен быть закрыт по причине банкротства | Б + ОЧ |
| 1 | Кредитный договор оформлен не Заявителем/Заявитель не оформлял | ОЧ / Мошенничество |
| 1 | Кредитный договор отображается в кредитной истории как открытый | ОЧ / Статус |
| 1 | Согласие на запрос кредитной истории не давал | ЗЗ / запросы |
| 1 | Не должно быть указанной просрочки/просрочек | ОЧ / Просрочка |
| 1 | Я на сво с декабря {YEAR}года должны списаться все кредиты и займы | Б (СВО) |
| 1 | В срок, не превышающий 30 … полностью удалить (исключить) из моей кредитной истории все сведения, | широкое удаление |

### 3.4. Склейка по ДУЛ

> Следует исключить ошибку, приводящую к «склейке» субъектов по ДУЛ. Ранее Вашей организацией в файле `{FILE}.xml` запись {N} по СКИ {FIO_ЧУЖОЙ} с ДУЛ {PASSPORT1} был передан ДУЛ {PASSPORT2}, который принадлежит нашему заявителю {FIO}.

Инструкция 3.1: `subjectBlocksCorrected` from/to **или** Title current/new. Контур **ЗС**.

## 4. Скоринг Бюро — `Исх.номер: OFL_…` (корпус `run/`, 23 письма)

> Запрос источнику формирования кредитной истории на основании заявления о внесении изменений и (или) дополнений субъекта кредитной истории (далее - Заявление)

Закрытие: 10 рабочих дней, п. 4.1 ст. 8; приложение — заявление субъекта.

| Формула | Контур |
|---------|--------|
| Прошу подтвердить достоверность переданных сведений: **Адрес:** {ADDR} по субъекту … {FIO} либо исправить информацию… | ТЧ / Адрес |
| … **Документов: паспорт** [ИНН] [СНИЛС] [Места рождения] … | ТЧ / Паспорт |
| Прошу подтвердить **правомерность запроса** кредитного отчета субъекта {FIO} в указанные в заявлении даты {DATE}; **Кредитный отчет; Микрозайм** | ЗЗ / запросы |
| … **Кредитный отчет; Заключение и исполнение договора** | ЗЗ / запросы |
| … сведений **(Просрочки)** по договору УИД: {UID} … | ОЧ / Просрочка |
| … **(Статус)** по договору УИД: {UID} … | ОЧ / Статус |
| … **(Факт оформления)** по договору УИД: {UID} … | заявка vs договор — сверка ПО |
| … информации **(Факт оформления) в информационной части** УИД: {UID}… | ЗЗ / Заявка |
