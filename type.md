**Виды оспариваний** (кратко). Полный справочник типов и подтипов — только [classification.md](classification.md).

| Тег | Расшифровка |
|-----|-------------|
| **ТЧ** | Титульная часть — ПДн: ФИО, паспорт, адреса, контакты |
| **ОЧ** | Основная часть — договор: статус, просрочки, суммы, продажа |
| **Б** | Банкротство |
| **ЗЗ** | Запросы и заявки |
| **ЗС** | Задвоение / склейка субъектов |

Несколько контуров в одном пакете → **смешанный**: все применимые теги (см. classification.md §3).
