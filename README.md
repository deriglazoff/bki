# Оспаривание КИ

Рабочая база знаний и агентские сценарии для задач оспаривания кредитной истории в Bitrix.

**Цель:** по URL задачи получить в чате классификацию, сверку ПО, решение по контурам и черновик ответа — чтобы сотрудник мог исполнить (ЛК бюро, выгрузка, файл удаления, XML), не разбирая пакет с нуля.

Агент **не** делает DML в ПО, не шлёт файлы в бюро и не закрывает задачу.

## Быстрый старт

1. Глоссарий — [CONTEXT.md](CONTEXT.md)
2. Типы и подтипы — [classification.md](classification.md)
3. План сотрудника — [guide/README.md](guide/README.md), с [00-obshiy-algoritm.md](guide/00-obshiy-algoritm.md)
4. Для агента — [AGENTS.md](AGENTS.md)

## Скиллы Cursor

- **classify-osparivanie** — только теги в комментарий задачи
- **solve-osparivanie** — полный assistive-прогон (классификация + ПО + решение + черновик)
