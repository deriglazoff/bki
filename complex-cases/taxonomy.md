# Таксономия оспариваний

Определения типов и подтипов — только в [classification.md](../classification.md). Этот файл — маршрутизация контуров работ, не второй справочник меток.

Типы в тегах Bitrix **взаимно исключающие**, кроме **смешанного пакета**: тогда явно «смешанный» и **два и более** типовых тега (см. classification.md §3).

## Маршрутизация

| Тег | Доля потока (2026) | Контур | Что делает assistive |
|-----|-------------------|--------|----------------------|
| **ЗЗ** | 54% (1149) | Полный автомат (буткемп / 80%) | Файл на удаление запросов, задача, ожидание бюро |
| **ОЧ** | 26% (553) | Волна A: шаблоны | Карточка договора, сверка 3 бюро, черновик ответа/выгрузки |
| **ТЧ** | 13.5% (287) | Волна B: assistive | Факты + аналоги + рекомендация, без автозакрытия |
| **Б** | 4.7% (101) | Волна B: assistive | Правовая сверка банкротства vs просрочка/статус |
| **ЗС** | 1.9% (41) | Волна B: playbook | Чеклист demerge, не ML |
| запрос ССП | 0.3% (7) | Подтип ЗЗ | Как ЗЗ |

**Тяжёлый хвост (20.1%)** = ТЧ + Б + ЗС. По корпусу ОЧ ближе к ЗЗ (короткие шаблонные сверки); AI-assistive нужен на ТЧ/Б/ЗС.

## Признаки для классификации входящего

Полные правила (пакет НБКИ Исх+Вх) — в [classification.md](../classification.md) §3. Краткие ориентиры:

| Признаки в теме / файле | Тип |
|-------------------------|-----|
| запрос, заявка, удаление запросов, ССП | ЗЗ |
| договор, просрочка, статус кредита, сумма, платеж | ОЧ |
| паспорт, адрес, ФИО, место рождения, титул | ТЧ |
| банкрот, реализация, реструктуризация | Б |
| склейка, задвоение, два СКИ, разделение, demerge | ЗС |
| несколько контуров в одном пакете | смешанный: все применимые теги |
| низкая уверенность | человек |

**Смешанный пакет** (запросы + договор + титул и любой стык контуров): ставить **все** теги, делать все контуры, один финальный ответ по пунктам. ЗЗ-часть не сваливать в авто-ЗЗ вместе с кредитом; ОЧ/ТЧ/Б — по своим гайдам. Не сводить к одному «доминантному» типу.

| ПрОтв | Проект ответа |

| 6+ / 10+ | Долгий цикл (прокси сложности) |

## Запреты маршрутизации

- ТЧ / Б / ЗС не идут в автосценарий удаления запросов.
- ОЧ с признаком банкротства → эскалация в контур Б, не шаблон «корректно».
- Клиент или договор не найдены в ПО → эскалация, не отказ в оспаривании.
