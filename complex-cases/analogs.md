# Индекс аналогов

Индекс строится по **человеческим** комментариям завершённых задач (без системных сообщений и плейсхолдеров `[файл]`).

## Каталоги

| Файл | Тип | Кейсов с текстом | Ключ поиска |
|------|-----|------------------|-------------|
| [analogs-ТЧ.json](analogs-ТЧ.json) | ТЧ | 228 | `subtype`: passport / address / fio / birthplace / glue_signal (+ `+interim`) |
| [analogs-Б.json](analogs-Б.json) | Б | 87 | `subtype`: korrektno_law / bankrot_fix / pko_bankrot |
| [analogs-ЗС.json](analogs-ЗС.json) | ЗС | 32 | Справочник для playbook, не ранжирование модели |

Каждая запись:

- `task_id`, `url`, `tags`
- `subtype` — ветка аналога
- `n_human_msgs` — прокси трудоёмкости
- `snippet` — первый содержательный комментарий
- `has_interim` — был промежуточный ответ

## Как подбирать

1. Определить `case_type` и `mismatch_kind` / `branch` из карточки фактов.
2. Отфильтровать каталог по `subtype`.
3. Взять топ-1…3 по `n_human_msgs` (или ручной curated shortlist).
4. В рекомендацию: ссылка на задачу + одна фраза «что сделали», без копирования ПДн лишним объёмом.

**Не индексировать:** системные «новый чат», смену исполнителя, голые `[файл] N`.

**Ограничение выгрузки:** ~294 задачи с мигрированным чатом — старые комментарии неполные. Для продакшена догрузить историю до миграции и сами вложения (в CSV только Disk ID).
