## Сценарий 1 — ОЧ шаблон (R4)

**Вход:** оспаривание по договору, в ПО договор закрыт, в ОКБ закрытия нет, НБКИ и Экви — закрыт.

**Система показывает:**

- Карточку [och-card.md](och-card.md) с таблицей 3 бюро.
- `decision.rule_id = R4`, `action = draft_correction`.
- Стоп: не отвечать клиенту, пока выгрузка не принята.
- Кнопка/блок «черновик выгрузки» (без реальной отправки).

**Не делает:** автоотправку в бюро, SQL.

**Референс из золота:** ветка `zakryt` / `korrektirovka` в [och-gold-set.md](och-gold-set.md).

## Сценарий 2 — ОЧ отказ (R3)

**Вход:** договор открыт, просрочка есть, во всех трёх бюро то же.

**Система:** `R3 draft_refusal`, черновик «отображается корректно», можно «готовь ответ».

---

## Сценарий 3 — ТЧ эскалация

**Вход (из корпуса):** индекс адреса не совпадает; адреса из письма клиента нет в кредитном отчёте; в ПО адрес корректный.

**Система:**

- Карточка ТЧ, `mismatch_kind = address`.
- Рекомендация: уточнить у бюро / не закрывать как «корректно» без ответа НБКИ.
- `needs_interim = true`, статус `awaiting_bureau` после письма в бюро.
- 1–2 аналога из [analogs-ТЧ.json](analogs-ТЧ.json) subtype `address` / `address+interim`.
- Guardrail G1: не выбирать сторону при расхождении.

**Не делает:** автозакрытие, удаление запросов.

Референс: задача вроде 451341 (промежуточный + письмо в НБКИ) — в каталоге ТЧ.

---

## Сценарий 4 — Б правовая сверка

**Вход:** клиент признан банкротом на дату D; в ПО и БКИ просрочка только до D.

**Система:**

- Карточка Б, `branch = korrektno_law`.
- Черновик: начисление процентов/пеней прекращается с даты признания; дни просрочки могут продолжаться; сведения корректны.
- Если Bankrot не ушёл в одно бюро → `bankrot_fix` + корректировка + стоп до выгрузки.

Референс: subtype `korrektno_law` в [analogs-Б.json](analogs-Б.json).

## Сценарий 5 (опционально) — ЗС playbook

**Вход:** два клиента, один паспорт; нужен файл на разделение.

**Система:** чеклист из [zs-playbook.md](zs-playbook.md), `needs_interim = true`, без автозакрытия.

## Критерий успешного демо

- Классификатор / тег не сваливает ТЧ/Б/ЗС в авто-ЗЗ.
- По ОЧ видна таблица 3 бюро и шаблон (сценарии 1–2).
- По ТЧ и Б — рекомендация + эскалация / правовая ветка, задача не закрыта системой.
- Промежуточный ответ назван статусом, не только комментарием в чате.
- На слайде ценности: **20% потока / ~32% комментариев** для ТЧ+Б+ЗС; отдельно **26% ОЧ** под шаблоны.
